SUPER FANCY PANTS ADVENTURE
FANCY MOD MANAGER BUILD 11 PRO

HOW TO START
1. Close Super Fancy Pants Adventure.
2. Extract this entire folder.
3. Run Launch Fancy Mod Manager.bat.
4. Choose SFPA.exe if asked.
5. Press Launch Game.
6. Load a level, then press Tab or ` to open the runtime menu.

BUILD 11 HIGHLIGHTS

MEGA STYLE RUNTIME UI
Build 11 uses a compact dark multicolumn runtime panel inspired by dense mod menus such as Mega Hack. Player, Movement, Combat, World, Utility, Cosmetic, and Display controls are visible side by side. Use the search box to filter controls instantly.

NOCLIP CAMERA REBUILD
Noclip no longer returns out of the collision routine before the normal camera bookkeeping. When Noclip is active, collision work is skipped and execution jumps into the shared end of the routine where the player camera update still runs.

FULL ENEMY FREEZE
Freeze Enemies now guards the shared enemy update, enemy movement check, and after move processing. It is intended to freeze enemy movement and behavior rather than only their animation.

SUMMON ENEMY
Open the World column, choose an enemy from the dropdown, and press SPAWN. Every press creates another enemy near Fancy Pants. Included summon types are Baddie1, Spider, Bat, Bird, Mouse, Ninja, InkFly, InkBall, InkFloat, SnailShell, Volleyball, and Bowling Ball.

MORE INDIVIDUAL MODS
Build 11 adds dynamic individual controls for Random Speed, Cycle Speed, Pulse Speed, Random Jump, Cycle Jump, Pulse Jump, Random Power, Cycle Power, Pulse Power, Random Time, Cycle Time, Pulse Time, Random FPS, Cycle FPS, and Pulse FPS. The menu also exposes many exact speed, jump, power, time, and FPS values as separate searchable controls.

STABILITY
Build 11 stays on the crash safe save loading core. TPS and frame interpolation hooks remain excluded. Custom art stays disabled by default and falls back to the stable base file if validation fails.

BACKUP
The manager preserves SFPA.original.swf as the verified original backup. Use Restore Original after closing the game if you want the untouched game back.

NOTES
Summoned enemies use a generic spawn setup. Some enemy types may behave differently outside the rooms where the original game normally creates them.
